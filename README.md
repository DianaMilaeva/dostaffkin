# Dostaffkin — полный проект Angular

Это самостоятельный Angular-проект, подготовленный из исходного ZIP `delivery.zip`. В комплект входят конфигурация Angular, TypeScript-компоненты, HTML-шаблоны, CSS и адаптивные стили, шрифты, изображения и SVG-иконки.

## Что перенесено

- Главная страница (`/`), оформление доставки (`/order`) и отслеживание посылки (`/track`).
- Общая шапка и переходы между страницами через Angular Router.
- Все изображения, фоновые изображения, изображения размеров посылок, SVG-иконки и шрифты Roboto.
- Стили и адаптивные правила всех трёх исходных страниц.
- Выбор размера посылки и скорости доставки, тарифы и минимальная стоимость, расчёт маршрута и времени доставки, показ итоговой суммы.
- Форма заявки, проверка имени и телефона, демонстрационное подтверждение и номер отправления.
- Демонстрационная логика отслеживания отправлений с номерами от 1000 до 10000.
- Сохранён исходный загрузчик подсказок/карт из `order.html` и оба его атрибута ключей `data-apikey` и `data-suggest-apikey` в `src/index.html`.

## Как запустить на компьютере

Нужен Node.js подходящей версии для Angular 20 (рекомендуется Node.js 20.19+ или 22.12+).

1. Распакуйте архив в отдельную папку.
2. Откройте эту папку в VS Code или терминале.
3. Выполните:

   ```bash
   npm install
   npm start
   ```

4. Откройте адрес, который покажет Angular CLI (обычно `http://localhost:4200`).

Для проверки производственной сборки:

```bash
npm run build
```

## Важно про карту, ключи и логику

- В `src/index.html` сохранена исходная строка подключения `https://testologia.ru/ymc_min.js` с исходными значениями `data-apikey` и `data-suggest-apikey`. Это те значения, которые находились в исходном `order.html`; они не были заменены заглушкой.
- Подсказки и построение маршрута зависят от доступности внешнего скрипта и действительности этих ключей. Если сервис или ключи ограничены, карта/расчёт могут не заработать без изменений со стороны владельца сервиса.
- В исходном проекте нет серверного API для создания заказов и получения реальных статусов. Поэтому отправка заявки и отслеживание сохранены как демонстрационные функции, а не как настоящая серверная доставка.
- Ключи, находящиеся в HTML, доступны посетителям сайта в браузере. Перед публичной публикацией убедитесь, что провайдер разрешает такой способ использования и что у ключей настроены допустимые домены/ограничения. Не добавляйте в репозиторий приватные серверные токены.

## Структура

- `src/app/pages/home/` — главная.
- `src/app/pages/order/` — оформление и расчёт доставки.
- `src/app/pages/track/` — демонстрационное отслеживание.
- `src/app/header/` — общая шапка.
- `src/styles.css` и CSS страниц — базовые и страничные стили.
- `public/images/`, `public/fonts/` — все ресурсы.
